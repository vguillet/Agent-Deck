# Client protocol v1

REST is rooted at `/api/v1`. Collection responses contain `items`, an optional
opaque `nextCursor`, and `asOfSequence`. Clients should fetch a snapshot, open
`/api/v1/stream`, register, and subscribe after the snapshot watermark.

```json
{
  "type": "register",
  "client": {
    "id": "stream-deck:device-id",
    "type": "stream-deck",
    "name": "Office XL",
    "version": "0.1.0",
    "capabilities": {
      "notifications": true,
      "images": true,
      "animations": true,
      "textInput": false,
      "approvalActions": false
    }
  }
}
```

After `registered`, send:

```json
{
  "type": "subscribe",
  "topics": ["agents.summary", "attention", "providers.health"],
  "afterSequence": 1842,
  "filter": {
    "providers": ["codex", "cursor-cloud"],
    "states": ["running", "waiting_for_approval", "ready_for_review"]
  }
}
```

Events are delivered as `{ "type": "event", "event": { ... } }`. A
`stream.resync_required` response means the requested sequence predates retained
history and the client must fetch a new REST snapshot.

The server disconnects clients with close code `1013` when their output buffer
exceeds 1 MiB. Clients should reconnect with exponential backoff and the last
processed sequence.

Client configuration is an opaque revisioned document. Updates may send
`If-Match: "<revision>"`; stale revisions receive HTTP 409.

Agents may include navigation links:

```json
{
  "rel": "focus",
  "label": "Open in Cursor",
  "href": "cursor://agent-deck.focus/open?conversationId=..."
}
```

`focus` requests application switching and `view` opens a non-primary
inspection surface. These are client-side navigation hints; opening them does
not create a command or canonical event.
